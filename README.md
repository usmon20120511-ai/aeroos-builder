# aeroOS Builder

Небольшой набор PowerShell-скриптов, который из **официального ISO Windows 11**, который ты скачал сам, собирает облегчённый установщик с брендом aeroOS.

**Внутри этого пакета нет ни одного бинарника Windows, ни одного драйвера, ни одного личного фото/видео, ни одного установщика сторонних программ.** Только текст: скрипты, конфиги, рецепт и документация. ISO ты подаёшь на вход сам — ровно как в `tiny11builder` у NTDEV.

> Это не пиратская копия Windows, не активатор и не «новая ОС». Это рецепт настройки собственной лицензионной копии. См. [NOTICE.md](NOTICE.md).

---

## Что умеет

- Убрать лишние Store-приложения, capability, фичи и пакеты (список в `recipes/aeroos-public.json`)
- Убрать / отключить Defender и Edge **внутри образа** (офлайн, текущая система не трогается)
- Отключить телеметрию, поиск в сети, фоновые службы и «рекламные» ключи нового пользователя
- Переименовать образ, метку ISO, BCD, `ProductName`, OEM-строки, имя компьютера в `aeroOS`
- Настроить «макоподобный» интерфейс через ExplorerPatcher + реестр (центрированная панель, мелкие иконки и т.д.)
- При первом запуске поставить Node.js, Temurin JDK, Chrome, Git, Python, VS Code и ExplorerPatcher — **все скачиваются с официальных сайтов во время сборки**, в пакете их нет
- Не внедрять вообще никакие драйверы (по умолчанию). Хочешь свои — передай `-DriverFolder`

## Что НЕ умеет (специально)

- Не обходит активацию и не меняет `setup.exe` (подпись Microsoft остаётся целой)
- Не содержит твоего видео, твоего фото, обоев Apple и драйверов твоего ноута
- Не меняет твою текущую Windows — вся работа идёт со смонтированным **офлайн-образом WIM**

## Быстрый старт

```powershell
# 1. Скачай официальный ISO Windows 11 Pro ru-ru с сайта Microsoft
#    и положи, например, в C:\ISO\

# 2. Запусти сборку от имени администратора
powershell -ExecutionPolicy Bypass -File .\scripts\Build-AeroOS.ps1 `
  -SourceIso 'C:\ISO\Windows11_Pro_ru-ru_x64.iso'
```

Готовый ISO появится на Рабочем столе. Подробнее — [USAGE.md](USAGE.md).

## Требования

- Windows 10/11 x64, права администратора
- **Windows ADK → Deployment Tools** (нужен `oscdimg.exe`) — [официальная ссылка](https://learn.microsoft.com/windows-hardware/get-started/adk-install)
- 25–35 ГБ свободного места на диске
- Интернет только для скачивания установщиков приложений (примерно 600 МБ)

## Структура

```
aeroOS-Builder/
├─ README.md                     этот файл
├─ USAGE.md                      пошаговая инструкция и устранение проблем
├─ NOTICE.md                     авторство, лицензии, дисклеймер
├─ LICENSE                       MIT для самих скриптов

│  └─ aeroos-public.json         что удаляем и что пишем в реестр
├─ config/
│  ├─ apps.json                  официальные URL установщиков + хэши
│  └─ SetupComplete.cmd.template шаблон установщика первого запуска
└─ scripts/
   ├─ common.ps1                 общие функции
   ├─ Build-AeroOS.ps1           точка входа
   ├─ 0-Prepare-Image.ps1        распаковка ISO, выбор издания, монтирование WIM
   ├─ 1-Strip-Image.ps1          удаление софта, Defender, Edge, служб
   ├─ 2-Set-AeroOSBrand.ps1      брендинг, реестр, опциональное видео
   ├─ 3-Add-DevApps.ps1          скачивание и интеграция приложений
   └─ 4-Export-BuildIso.ps1      экспорт WIM, BCD, сборка и проверка ISO
```

## Лицензия и даже не думай выкладывать ISO

Скрипты — MIT, выкладывай их где хочешь. **Сам ISO выкладывать нельзя** — лицензия Microsoft запрещает распространение установочных образов. Именно поэтому этот пакет и сделан «как у tiny11»: инструмент публичный, результат каждый собирает себе сам.

Подробнее и с формулировками — в [NOTICE.md](NOTICE.md).
